# Интерактивный прототип CRM «IT-Факультеты»

Минималистичный прототип на HTML, CSS и JavaScript для обсуждения интерфейса по проекту ТЗ v0.2. Данные учеников, платежей и переписки демонстрационные. Подключений к Listok, платёжным сервисам и мессенджерам нет.

## Открытие

Откройте `outputs/CRM_IT-Факультеты_прототип.html` в браузере. Это один автономный файл: его можно отправить руководителю, он работает без установки и интернета.

Для разработки запустите из корня проекта:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

Откройте `http://127.0.0.1:4173/`. После изменения исходников соберите переносимый файл командой `node build.mjs`.

## Варианты

Кнопка «Варианты» открывает переключатели. На каждый элемент предусмотрено не больше трёх решений:

| Элемент | Варианты |
| --- | --- |
| Навигация | Слева / сверху |
| Ученики | Таблица / карточки |
| Карточка ученика | Панель справа / окно / отдельная страница |
| Расписание | День / неделя / список |
| Оплаты | Таблица / карточки по ученикам |
| Задачи | Список / доска |
| Плотность | Обычная / компактная |
| Тема | Светлая / тёмная |
| Родитель в списке | Показывать / скрывать |

Выбор сохраняется в текущем браузере, если доступно локальное хранилище. «Сохранить выбор» скачивает JSON с настройками, который можно передать разработчику. «По умолчанию» восстанавливает исходный интерфейс.

## Сценарии для просмотра

1. Рабочий день: занятия, задачи, семьи для контакта и подключение к боту.
2. Ученики: поиск по ученику или родителю, фильтр статуса, создание лида со сделкой, карточка с заметкой, история посещений и платежей, документы.
3. Группы и расписание: состав, создание группы и занятия, отметки посещения, перенос с сохранением состава, отмена и восстановление.
4. Оплаты: остаток занятий отдельно от денежных поступлений, история операций, справочник цен и образец ссылки заказчика.
5. Сообщения: отдельная переписка Telegram и MAX, приглашение отдельно от подключения семьи, пример напоминания и подтверждения получения, демо-рассылка.
6. Задачи и воронка: создание, выполнение и изменение состояния задачи, три примерных этапа сделки.
7. Сотрудники: пример отображения ролей, смен и преподавателей.

Демо-изменения данных и прикреплённые файлы доступны до обновления страницы. «Сбросить демо» восстанавливает базу, сохраняя варианты интерфейса. Прототип не отправляет сообщений и не выполняет платежей.

Цены, состояния задач и этапы воронки — примеры для обсуждения. Финансовые правила, права доступа, миграция, интеграции, сессии и отработки требуют дальнейшего уточнения ТЗ. Отметка посещения не списывает занятия с абонемента. Ссылка `https://it-deti.ru/5700` показана как образец без привязки к демонстрационным тарифам.
